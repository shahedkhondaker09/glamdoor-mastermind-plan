# AI Agents for Scale (Social + SEO)

## Agent 1: Content Creator Bot
- **Task:** Generate 3 Reel scripts daily
- **Tools:** ChatGPT API (batch) + Canva auto-design + Make/Zapier auto-post
- **Output:** 21 scripted Reels for Week 1
- **Schedule:** Run daily at 7 AM GST

## Agent 2: Zone-Based Outreach Bot
- **Task:** Write 5 WhatsApp messages per zone (personalized)
- **Tools:** ChatGPT API
- **Output:** 50+ copy-paste variations across Marina/Downtown/JVC
- **Zones:** Marina, Downtown, Jumeirah, JVC, Al Barsha

## Agent 3: SEO Blog + Google Business Optimizer
- **Task:** Generate 300-word SEO posts: "Best Salons in [Zone] for [Service]"
- **Tools:** ChatGPT batch + WordPress auto-publish
- **Output:** 20+ posts (4 zones × 5 services)
- **Services:** Nails, Hair, Skin, Makeup, Spa

## Agent 4: Email Drip Automation
- **Task:** Auto 5-email sequence to landing page visitors
- **Tools:** Zapier + HubSpot/Mailchimp
- **Sequence:**
  - Day 0: Welcome + demo
  - Day 2: Social proof
  - Day 4: Limited offer
  - Day 6: Referral
  - Day 8: Last chance

## Agent 5: Influencer Manager
- **Task:** Generate personalized DM outreach (10 influencers)
- **Tools:** ChatGPT API
- **Include:** @ handle, specific post reference, offer (free service + AED 50 credit)
- **Output:** 10 ready-to-send DMs (send manually for best open rates)
