# 🌟 GlamDoor Dubai 7-Day Mastermind Plan

Week 1 launch strategy for **GlamDoor** — a salon booking platform connecting customers with Dubai salons.

## 🎯 Goal
50+ leads, 10+ partner sign-ups, 3+ confirmed bookings in 7 days.

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/shahedkhondaker09/glamdoor-mastermind-plan.git
cd glamdoor-mastermind-plan

# Install dependencies
pip install -r requirements.txt

# Regenerate the PDF plan
python3 docs/GlamDoor_Dubai_7Day_Mastermind_Plan.py
```

## 📊 Key Targets (Week 1)
| Metric | Target |
|--------|--------|
| Leads | 50-80 |
| Partners onboarded | 10-15 |
| Confirmed bookings | 3-5 |
| Cost per lead | < AED 40 |
| Social reach | > 50K |

## 📍 Dubai Zones
- **Tier 1:** Marina, Downtown, Jumeirah
- **Tier 2:** Deira, Al Barsha, Mirdif, Al Wasl
- **Tier 3:** Sharjah, Abu Dhabi (Week 2+)

## 🛠 Toolstack
- **Landing page:** Carrd / Framer
- **Booking:** Cal.com
- **Email:** HubSpot free tier
- **WhatsApp:** Twilio
- **Social:** Buffer + Canva + CapCut
- **Automation:** Make.com / Zapier / N8n
- **AI:** ChatGPT API
